# ff14-macro-helper

FFXIV のマクロを、ゲーム内エディタより書きやすく、確認しやすくする日本語 Web アプリケーションである。

MVP は CUI に慣れたエンジニア適性のあるゲーマー向けのコードエディタとして提供する。入力補完、構文ハイライト、lint、チップヘルプ、コピー、URL 共有、簡易ログ実行を一画面で扱う。

## 目的

- 公式のテキストコマンド情報を、検索・補完・説明に使えるコマンド辞書として再構成する。
- 15 行・1 行 180 文字のゲーム内マクロ制約を、書いている最中に把握できるようにする。
- コピー前に、構文上の問題とログ上のおおまかな見え方を確認できるようにする。
- 将来の GUI マクロガイド／ノーコード組み立てのため、コマンド知識と編集体験を分離して蓄積する。

## 最優先の体験

PC ブラウザでマクロを入力すると、コマンドを補完でき、制約違反や不明な記述をその場で把握できる。完成した本文を 1 操作でゲーム内へ貼り付けられ、URL を渡せば同じ内容を他者と共有できる。

## MVP の範囲

- 日本語版 FFXIV 公式テキストコマンドを基にした検索可能なコマンド辞書
- テキストエディタ、構文ハイライト、`/a` から `/ac` を候補に出す入力補完、チップヘルプ
- 行数・行長・空行・未知コマンド・代表的な引数形式の lint
- `/sh`、`/p`、`/echo`、`/ac`、`/wait` などを、見た目を区別したテキストログとして順に確認する簡易実行
- マクロ本文のコピー、URL クエリへの可逆な埋め込み、URL からの復元
- PC ブラウザ向けのレイアウト

## 非目標

- ゲームクライアントを操作すること、またはゲーム内挙動を完全に再現すること
- 戦闘状態、対象、ジョブ、クールダウン、コンフィグを必要とする実行可否の断定
- ユーザー登録、クラウド同期、共同編集、公開マクロ集
- モバイル最適化、多言語、ドラッグ&ドロップによる GUI 組み立て
- 公式情報を無確認で AI が生成・更新すること

## 技術方針

- TypeScript を中心に、PC ブラウザで完結する静的 Web アプリとして開始する。
- コマンド辞書はアプリに同梱するバージョン管理済みデータとし、公式情報を根拠として人がレビューする。
- URL を共有の正本とする。編集途中の復元だけが必要なら端末内保存を補助的に用いる。
- MVP に DB は導入しない。共有リンクの短縮、公開マクロ、ユーザー保存などで永続 DB が必要になった場合は Neon を使う。
