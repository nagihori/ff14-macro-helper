# content/ — 記事と下書き

サイトの記事（`/articles`）の元になる Markdown を置く場所です。

```
content/
  articles/   公開する記事。1 ファイル = 1 記事。ファイル名が URL（/articles/{ファイル名}）
  drafts/     下書き・書きたいことのメモ。公開されない（サイトには出ない）
```

## 記事の書き方

`content/articles/{slug}.md` を作ります。slug は半角の小文字・数字・ハイフンだけ（例：`wait-time-guide.md`）。
先頭に、`---` で囲んだ設定（フロントマター）を書きます。

```markdown
---
title: 待機時間の決め方
date: 2026-10-03
description: 一覧と共有カードに出る、1〜2 文の説明（省略できます）
tags: [マクロ, 製作]
---

ここから本文（Markdown）。

## 見出し

- 箇条書き
- `<wait.3>` のようなコードは、バッククォートで囲みます

::macro[abc12345]

上の行のように `::macro[マクロの slug]` だけの行を書くと、公開マクロがコードつきでその場に出ます。
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `title` | 必須 | 記事のタイトル |
| `date` | 必須 | `YYYY-MM-DD`。一覧は新しい日付が上 |
| `description` | 任意 | 一覧・`<meta>`・共有カード・フィードに出る説明 |
| `tags` | 任意 | `[a, b]` または `a, b`（記事の表示用。タグ別一覧とは別） |

- 改行は、そのまま改行として出ます（1 文ごとに改行して書けます）。段落を分けたいときは、空行を入れます。
- HTML コメント（`<!-- … -->`）は、**記事には出ません**（公開時に消えます）。「あとで直す」メモや、書きかけの部分を、コメントにして置けます。コードブロックやインラインコードの中は、書き方の例なので消えません。
- 使える Markdown：見出し・段落・箇条書き・番号つき・引用・コード・コードブロック・表・リンク・画像・区切り線。
- **本文に直接書いた HTML は、タグとして通らず、文字として出ます**（安全のため）。
- リンクは `http(s)://`・`mailto:`・サイト内のパス（`/macros/…`）・`#アンカー` だけ。外部リンクは別タブで開きます。
- 記事に埋め込んだマクロには、`copy`（コピー）と `edit`（エディタで編集）の操作帯が付き、記事の**最初の 1 つ**の上に「この記事のマクロは、コピーして、ゲームで試せます」という 1 行が**自動で**出ます（記事ごとに書かなくて大丈夫です）。
- 記事の末尾には、「マクロエディタを開く」「公開マクロを探す」の小さな案内が**自動で**付きます。
- `::macro[slug]` は、公開中のマクロだけ表示できます。見つからないときは、小さな案内が出ます（記事は壊れません）。コードブロックの中に書いた `::macro[…]` は、書き方の例なので埋め込まれません。
- フロントマターに間違いがある記事は、サイト全体を落とさずに、ビルドのログに理由を出して飛ばします。

## 公開する

1. `content/drafts/` で書き、できあがったら `content/articles/` に移す（または新しく作る）。
2. `npm run dev` で `/articles/{slug}` を見て確かめる（開発中は書き換えがすぐ反映されます。フッターの「記事」リンクは、`next dev` を起動し直すと出ます）。
3. PR にしてマージすると、デプロイで公開されます。

記事が 1 本もないあいだは、`/articles` は検索に載らず、フッターのリンクも出ません。

## 下書き（drafts/）

「今度これを書こう」の箇条書き、書きかけの文章、資料のメモなど、自由な形で置けます。サイトには出ません。
Claude に「`content/drafts/xxx.md` の箇条書きから、記事を `content/articles/` に下書きして」と頼むこともできます。

`content/drafts/` の中身は、**Git の管理に入れない設定**（`content/drafts/.gitignore`）にしてあります。リポジトリを公開しても、書きかけのメモは出ません（履歴は後から消せないため）。下書きも Git に残したいときは、この `.gitignore` を消してください。
