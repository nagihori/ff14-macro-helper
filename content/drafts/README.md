# drafts/ — 下書きとメモ

ここは公開されません（サイトにも、Git にも入りません）。自由に置いてください。

- 「今度これを書こう」の箇条書き
- 書きかけの記事（フロントマターは、公開するときに足せば大丈夫です）
- 資料・リンクのメモ

Claude に頼むときの例：
- 「`content/drafts/ideas.md` の 3 つ目を、記事にして `content/articles/` に下書きして」
- 「この箇条書きから、見出しの構成案だけ出して」

できあがったら `content/articles/{slug}.md` に移し、フロントマター（`title`・`date`）を付けます。書き方は `content/README.md` にあります。
