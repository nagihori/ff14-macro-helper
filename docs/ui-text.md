# ボタン文言の対応表

定義は [`src/lib/ui-text.ts`](../src/lib/ui-text.ts)。方針は「対象を明示する。対象が無い場面だけ『〇〇する』」。

| 定数 | 文言 | 使う場所 |
|---|---|---|
| `copyMacro` | マクロテキストをコピー | アクションボタン群（エディタ下部・詳細ページ） |
| `copyShareUrl` | 共有URLをコピー | アクションボタン群（エディタ下部） |
| `copyPageUrl` | URLをコピー | 詳細ページの共有ボタンのキャプション |
| `share` | URLを共有 | 詳細ページの共有。共有シートが使える端末（スマホなど）のみ「URLをコピー」の代わりに使う |
| `editInEditor` | エディタで編集 | 詳細ページ |
| `preview` | 動作プレビュー | アクションボタン群（エディタ下部） |
| `tabEditor` / `tabLibrary` | エディタ / ライブラリ | 全ページ共通ヘッダーのタブ |
| `publish` | 公開する | エディタのアクションボタン群（編集中のマクロを公開フォームへ送る） |
| `submitMacro` | 自作マクロを投稿 | ライブラリの件数の横（新しくマクロを投稿する入口） |
| `copied` | コピーしました | 成功時。チェックアイコン＋文言・句点なし |
| `copyFailed` | コピーできませんでした | 失敗時。バツアイコン＋文言・句点なし |

操作帯（コードブロック上部）は短い英小文字のキャプション（`BAR_TEXT`：copy / share / preview / edit）。正式名は `title` / `aria-label` に持たせる。

## 用語の使い分け

- 「公開」と「投稿」：エディタ側は「公開する」（編集中のマクロを公開マクロ側へ展開する意味）。ライブラリ側は「投稿」（新たにマクロを持ち込む、ユーザーの行動に合わせる）
- 「共有URL」（スペースなし）：エディタのマクロ本文を載せた `?m=` の URL。「マクロURL」：公開マクロの詳細ページの URL（旧「ページURL」）
- 「エディタ」「ライブラリ」：サイト全体のタブ名。ページの見出しは「マクロエディタ」「公開マクロを探す」のまま。
- 「マクロエディタ」：単体で言うとき。「エディタで〜」と続くときは「エディタ」
